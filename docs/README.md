# ollamacmf documentation

Start with the repository [README](https://github.com/infosave2007/ollamacmf#readme). The pages specific to this fork are:

- [User guide](./cmf.md) — install, get models, configure, API, troubleshooting.
- [Model catalog](./cmf-models.md) — CMF models on Hugging Face with sizes and pull commands.
- [Maintainer notes](./cmf-engine.md) — how CMF support is wired into Ollama, the runtime lock, releases, tests.
- [Runtime updates](./cmf-release-automation.md) — how a new Cortiq release becomes the pinned runtime.
- [Development](./development.md) — building the native Ollama runners and the CI layout.

The remaining files in this directory are inherited from upstream Ollama and describe upstream features. They are kept for reference; the published documentation site (`docs.json`, `.mintignore`) shows only the pages above. For current upstream documentation see [docs.ollama.com](https://docs.ollama.com).
