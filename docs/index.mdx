`ollamacmf` is Ollama with native support for [CMF](https://github.com/infosave2007/cmf) models. Install it, start the server, and run a model from Hugging Face:

```sh
curl -fsSL https://raw.githubusercontent.com/infosave2007/ollamacmf/main/install.sh | sh
ollamacmf serve
ollamacmf run hf.co/infosave/LFM2.5-cmf:lfm2.5-230m-q4tp
```

The Cortiq runtime that executes CMF models is installed automatically. The Ollama API, the OpenAI-compatible API and the usual commands (`pull`, `run`, `list`, `show`, `rm`) all work as in Ollama.

## Commands at a glance

| Command | Purpose |
| --- | --- |
| `ollamacmf serve` | Start the server |
| `ollamacmf run hf.co/infosave/<repo>:<file>` | Chat with a model, downloading it first if needed |
| `ollamacmf pull hf.co/infosave/<repo>:<file>` | Download a model without starting a chat |
| `ollamacmf run ./model.cmf` | Import a local file and chat with it |
| `ollamacmf cmf import ./model.cmf --name NAME` | Import a local file under a name |
| `ollamacmf cmf search [QUERY]` | List CMF models on Hugging Face |
| `ollamacmf cmf status` | Show the runtime, the server and installed CMF models |
| `ollamacmf cmf setup` | Install the Cortiq runtime ahead of time |
| `ollamacmf list`, `show`, `ps`, `stop`, `cp`, `rm` | Manage models as in Ollama |
